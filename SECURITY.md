# Política de Seguridad

## Alcance

Este repositorio es un archivo editorial estático. No ejecuta backend,
no procesa datos personales, no almacena credenciales.

## Reporte de vulnerabilidades

**No uses Issues públicos** para reportar vulnerabilidades.

Usa una de estas vías:

1. **GitHub Security Advisories**
   https://github.com/Marcorojas17/KRONOSMV/security/advisories/new

2. **Correo privado del autor**
   Disponible en el perfil de GitHub: https://github.com/Marcorojas17

## Integridad criptográfica

Los archivos publicados se registran con hash **SHA-256** en
[`crypto/hashes.txt`](./crypto/hashes.txt). Cualquier alteración posterior
invalida la verificación.

## Autoría

SHA-256 comprueba **integridad**, no autoría. La autoría se establece por:

- El sello editorial `MB-2099-M045`
- El historial de commits en GitHub
- Firma GPG opcional de los tags (ver `crypto/README.md`)

## Claves privadas

**Nunca** se almacenan claves privadas en este repositorio. Solo hashes
y, en su caso, claves públicas.
